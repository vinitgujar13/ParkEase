Viva Explanation: Function vs. Procedure

Functions are invoked via SELECT and return a compute value (e.g., UUID from create_reservation() or parking fee from calculate_parking_fee()).
Procedures are invoked via CALL and perform administrative transaction-safe mutations or batch operations without requiring a direct query scalar return.

Cursor Mechanics in PL/pgSQL

The procedure uses standard ANSI/PostgreSQL cursor lifecycles: DECLARE facility_cursor CURSOR, followed by OPEN, FETCH ... INTO inside a loop terminating on NOT FOUND, and clean resource release via CLOSE.
